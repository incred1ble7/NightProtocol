# Night Protocol

Night Protocol — командный дипломный проект на Unity. Игрок заступает на ночную смену на станции и следит за обстановкой через камеры. Диспетчерская, комната отдыха и остальные помещения находятся внутри башни. Генератор стоит отдельно.

Звуковые эффекты из библиотек интегрируются в Unity через FMOD Studio. Для проекта используем материалы с лицензиями, разрешающими такое применение.
